# Nestly — каталог аренды квартир

Сервис долгосрочной аренды квартир: каталог с фильтрами, избранное и запись на просмотр.

## Возможности

- фильтры по району, количеству комнат и бюджету;
- карточки объектов и декоративная карта районов;
- избранное с сохранением в браузере;
- форма заявки с серверной валидацией;
- REST API, SQLite и интеграционные тесты;
- адаптивная версия для телефона.

## Запуск

```bash
pnpm install
pnpm start
```

Откройте `http://localhost:4600`. На Windows доступен `start-local.cmd`.

```bash
pnpm test
```
