# Тестовые платежи Nestly

Nestly бронирует первый календарный месяц аренды. Сумму в рублях берёт сервер из карточки квартиры. До подтверждения оплаты интервал удерживается 30 минут. Сервер сверяет сумму, валюту, идентификатор брони и признак тестового платежа перед подтверждением.

В окружении сервера задайте `APP_PUBLIC_ORIGIN` с HTTPS-адресом приложения, `YOO_KASSA_SHOP_ID` тестового магазина и `YOO_KASSA_TEST_KEY` с префиксом `test_`. Значения магазина храните в секретах окружения. При отсутствии обоих параметров магазин отключён. Неверный набор параметров останавливает запуск.

В тестовом магазине настройте HTTP-уведомления на `https://ваш-домен/api/payments/yookassa` для событий `payment.waiting_for_capture`, `payment.succeeded` и `payment.canceled`. Сервер подтверждает событие по API ЮKassa. После возврата из формы оплаты можно проверить её статус из кабинета арендатора.

Проверка в тестовом магазине

1. Откройте кабинет арендатора, создайте аккаунт и выберите свободный месяц.
2. Перейдите на страницу ЮKassa и используйте тестовую карту из документации провайдера.
3. Вернитесь в кабинет и проверьте статус «Забронировано» и занятый период в публичном календаре.
4. Проверьте отмену и повторный запрос на тот же период из другого аккаунта.
